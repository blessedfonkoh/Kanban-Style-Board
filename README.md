# Kanban Board

A command-line program that generates a **Kanban-style board** with editable lists and items. The interface allows you to load an existing board, edit its content, and save your progress for later use.

---

## ✅ Features

- 🧭 **Menu-driven interface** with 6 key options:
  1. **Display** the current Kanban board
  2. **Load** a saved board from a file
  3. **Edit an item** on a list
  4. **Edit a list** on the board (e.g., rename, reorder, etc.)
  5. **Save** the board to a file
  6. **Quit** the program

- 📂 **File-based storage** - boards are loaded from and saved to files in the same directory as the executable
- 📄 Comes with a **default board** pre-saved and ready to use

---

## 🚀 How It Works

- On launch, the program presents a numbered menu of actions
- You can edit both individual items and entire lists
- Boards are saved in a structured format so they can be reloaded in future sessions
- All interactions happen through the terminal/console

---

## 💾 File Storage

- Saved boards are stored locally in the same directory as the program
- You can load a board by selecting the corresponding menu option and entering the filename
- File saving uses a simple and readable format (custom or standard like CSV, depending on your implementation)

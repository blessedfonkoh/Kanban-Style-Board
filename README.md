A program that generates a Kanban-style board with lists that contain items 
and an interfaces that allows you to edit it, load it and save it 

This program does the following:
1) Display a menu with 6 options allowing for Display, Loading, Editing an item on a list, 
Editing a list on the board, Saving the Board to a file, and Quitting . The program 
also has a default board already saved.
2) The program loads a file , stored in the same directory as the executable. 
3) The program allows a user to Edit an item on a list
4) The program allows a user to edit a list on the board
5) Save the Board to a file so you can open up it up to save
6) 6) Quit: simply exit the program
